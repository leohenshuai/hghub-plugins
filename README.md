# HGhub 修复版片源

订阅地址：`https://raw.githubusercontent.com/leohenshuai/hghub-plugins/main/manifest.json`

原作：https://github.com/CoderL98/hghub-plugins 。2026-11 对 21 个源做了全量体检，范围是分类（第 1、2 页）、首页、搜索、详情、播放地址和视频流探测。共收录 19 个源（14 个修复 + 5 个新增）。

## 已知限制

- **AVToday、农民影视的搜索不可用**。前者被 Cloudflare 人机验证拦截，后者是站点自身的搜索模板缺失。插件会提示用户从分类浏览。
- 星芽接口偶尔要 10 秒以上才响应。
